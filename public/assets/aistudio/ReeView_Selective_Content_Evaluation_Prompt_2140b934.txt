REEVIEW — SELECTIVE CONTENT EVALUATION FEATURE
FULL IMPLEMENTATION PROMPT
============================================================

PROJECT CONTEXT
---------------
You are modifying the existing ReeView AI video evaluation website.

The current ReeView evaluator allows a user to upload a short-form Reel and receive an AI-based assessment. The current evaluation is based on four Reels Marketing Content characteristics:

1. Informational
2. Entertainment
3. Trendiness
4. Relatable

Each characteristic is evaluated using three assessment dimensions:

1. Interaction
2. Participation
3. Sharing

Each dimension receives a rating from 2 to 5.

IMPORTANT:
The existing research rubric / assessment criteria from the provided PDF must remain the authoritative source for scoring and evaluation. DO NOT replace, rewrite, simplify, invent, or change the original rubric criteria.

The new feature must ONLY add a user-controlled evaluation scope.

============================================================
MAIN FEATURE REQUEST
============================================================

Add a new section that allows the user to choose WHICH CONTENT CHARACTERISTICS they want ReeView to evaluate.

The user must be able to select:

- 1 characteristic
- 2 characteristics
- 3 characteristics
- all 4 characteristics

The selected characteristics determine the scope of the AI evaluation.

Example:

If the user selects only:

Entertainment

Then the AI must evaluate ONLY the Entertainment characteristic.

It must evaluate:

Entertainment
- Interaction
- Participation
- Sharing

The AI's explanation, score interpretation, strengths, weaknesses, and recommendations must all focus on Entertainment.

The AI must NOT provide an evaluation of Informational, Trendiness, or Relatable because those characteristics were not selected.

If the user selects:

Entertainment + Relatable

Then the AI must evaluate ONLY:

Entertainment
- Interaction
- Participation
- Sharing

Relatable
- Interaction
- Participation
- Sharing

The same principle applies for any combination of selected characteristics.

============================================================
FULL EVALUATION OPTION
============================================================

Add a clear option for:

FULL EVALUATION

Description:

"Evaluate all four content characteristics using the complete Reels Marketing Content Effectiveness Assessment."

Full Evaluation means:

- Informational
- Entertainment
- Trendiness
- Relatable

All four characteristics are evaluated using their original Interaction, Participation, and Sharing criteria.

When Full Evaluation is selected, the existing complete assessment behavior must remain available.

Selecting all four individual characteristics should produce the same complete evaluation as Full Evaluation.

Do not create a different scoring system for Full Evaluation.

============================================================
IMPORTANT: CONTENT FOCUS
============================================================

The new feature is about CONTENT, not audience targeting.

Do not make audience selection the primary evaluation scope.

The AI must evaluate the actual uploaded video content.

Existing fields such as:

- Primary Target Audience
- Campaign Objective
- Product or Brand Context

may remain in the interface if they are already part of the existing application, but they must NOT replace or override the selected content-characteristic evaluation.

These fields may provide context to the AI, but the official rubric score must be based on the selected content characteristics and their official criteria.

The selected content characteristics are the evaluation scope.

============================================================
OFFICIAL RUBRIC — DO NOT CHANGE
============================================================

The provided PDF is the authoritative source for the assessment criteria.

The four content characteristics are:

A. INFORMATIONAL CONTENT
B. ENTERTAINMENT CONTENT
C. TRENDINESS
D. RELATABLE CONTENT

Each characteristic has three assessment dimensions:

1. Interaction
2. Participation
3. Sharing

Each dimension receives a score from 2 to 5.

Use the exact meaning and scoring descriptions from the provided PDF for every selected characteristic.

DO NOT invent alternative criteria.

DO NOT use generic AI scoring criteria when the official rubric provides the relevant criterion.

The AI must determine the score by comparing the uploaded Reel's demonstrated content against the corresponding official rubric descriptions.

============================================================
SCORING FORMULA
============================================================

For every selected characteristic:

Variable Score =
(Interaction + Participation + Sharing) / 3

Each dimension is scored from 2.00 to 5.00.

Therefore each characteristic has a score from 2.00 to 5.00.

Use the official effectiveness interpretation from the PDF:

4.25–5.00
Very Effective

3.50–4.24
Effective

2.75–3.49
Moderately Effective

2.00–2.74
Less Effective

Do not change these ranges.

============================================================
IMPORTANT RULE FOR PARTIAL EVALUATIONS
============================================================

When fewer than four characteristics are selected:

DO NOT present the result as the official overall 20-point Reels Marketing Content Effectiveness Score.

The official overall assessment is based on all four characteristics.

Instead, show:

"Selected Content Evaluation"

and report the score of each selected characteristic.

You may also display:

"Selected Characteristics Average"

calculated as the average of the selected characteristic scores.

Example:

Selected characteristics:

Entertainment = 4.33
Relatable = 3.67

Selected Characteristics Average:
4.00 / 5.00

This is a selected-variable summary and NOT the official overall 20-point score.

Clearly label it so the user does not confuse it with the official overall assessment.

============================================================
OFFICIAL FULL EVALUATION SCORING
============================================================

Only when all four characteristics are evaluated should ReeView calculate the official Overall Reels Marketing Content Effectiveness Score.

Official formula:

Overall Score =
Informational +
Entertainment +
Trendiness +
Relatable

Minimum:
8.00

Maximum:
20.00

The official overall effectiveness interpretation must follow the provided PDF.

The existing Full Evaluation behavior should be preserved.

Do not create a new overall scoring method.

============================================================
AI EVALUATION SCOPE RULE
============================================================

This is the most important implementation rule.

The selected characteristics define the AI's evaluation scope.

The AI MUST:

1. Analyze the uploaded video.
2. Identify evidence relevant to the selected characteristics.
3. Evaluate each selected characteristic.
4. Evaluate Interaction, Participation, and Sharing for every selected characteristic.
5. Assign scores from 2 to 5 using the official PDF rubric.
6. Explain why each score was assigned.
7. Identify strengths related to the selected characteristics.
8. Identify areas for improvement related to the selected characteristics.
9. Give development recommendations related to the selected characteristics.
10. Keep the entire written analysis focused on the selected characteristics.

The AI MUST NOT:

- Score unselected characteristics.
- Give detailed commentary about unselected characteristics.
- Give recommendations for unselected characteristics.
- Claim that an unselected characteristic is effective or ineffective.
- Invent scores for unselected characteristics.
- Mention unselected characteristics as weaknesses unless explicitly necessary to explain that they were not evaluated.
- Use the unselected characteristics to calculate the partial evaluation.

Example:

User selects:
Entertainment only.

Correct:

Entertainment
Interaction: 4/5
Participation: 5/5
Sharing: 4/5
Variable Score: 4.33/5
Effectiveness: Very Effective

Strengths:
- Focus on entertaining elements.
- Attention capture.
- Engagement potential.

Areas for Improvement:
- Improvements specifically related to entertainment.

Recommendations:
- Recommendations specifically related to entertainment.

Incorrect:

Entertainment: 4.33
Informational: 3.00
Trendiness: 4.00
Relatable: 3.50

Do NOT do this when only Entertainment is selected.

============================================================
SCORING CONSISTENCY
============================================================

Do not let the AI score based on personal preference.

Scores must be grounded in visible/audible evidence from the uploaded Reel.

The AI should consider relevant multimodal evidence such as:

- Visual presentation
- Spoken content
- On-screen text
- Audio/music when relevant
- Editing
- Narrative/content structure
- Demonstrated use of content characteristics

However, evidence must always be interpreted through the selected characteristic's official rubric.

Do not award a high score simply because the video looks professionally edited.

Professional production quality alone is not sufficient unless it supports the specific rubric criterion being evaluated.

============================================================
RUBRIC FIDELITY
============================================================

The official PDF must remain the source of truth.

Do not:

- Change the wording meaning of the rubric.
- Change the 2–5 scoring scale.
- Change the Interaction / Participation / Sharing dimensions.
- Change the effectiveness ranges.
- Change the overall 8–20 scoring system.
- Invent additional official variables.
- Remove existing official variables.
- Replace the research criteria with generic marketing advice.

The new feature is a SELECTION LAYER, not a new research instrument.

============================================================
ERROR HANDLING
============================================================

If no variables are selected:

"Please select at least one content characteristic to evaluate."

If the AI returns a score for a characteristic that was not selected:

Do not render it.

The frontend should validate the response against selectedVariables before displaying the result.

If possible, also validate on the backend/API layer.

Never trust the model to enforce scope by itself.

============================================================
FRONTEND VALIDATION
============================================================

The frontend should know exactly which variables were selected before submitting the evaluation.

Send the selection with the video evaluation request.

Example:

{
  "video": "...",
  "evaluationScope": {
    "variables": [
      "entertainment",
      "relatable"
    ],
    "fullEvaluation": false
  }
}

The backend should use this scope when constructing the AI evaluation prompt.

============================================================
RESULT VALIDATION
============================================================

After the AI responds:

1. Check the selected variables.
2. Confirm that each selected variable has:
   - Interaction score
   - Participation score
   - Sharing score
   - Variable score
   - Effectiveness level
3. Confirm that no unselected variable is presented as evaluated.
4. Recalculate variable scores when possible rather than blindly trusting the model.
5. For Full Evaluation, calculate the official overall score from the four variable scores.
6. Use the official effectiveness ranges.
7. Render only the appropriate result sections.

The application should treat the AI as the evaluator of evidence, but the application should remain responsible for enforcing the scoring structure.

============================================================
ACADEMIC / RESEARCH INTEGRITY
============================================================

The purpose of this feature is to allow the user to choose the content characteristic(s) they want to assess while preserving the original research instrument.

Do not modify the research instrument.

The AI is evaluating demonstrated content characteristics and their potential to encourage Interaction, Participation, and Sharing.

Do not claim that the AI proves actual consumer behavior or causal effects.

Use language such as:

- "demonstrates"
- "indicates"
- "shows potential to encourage"
- "based on the assessment criteria"

Avoid unsupported claims such as:

- "will definitely increase engagement"
- "guarantees more shares"
- "proves consumers will buy"
- "causes higher engagement"

The PDF explicitly distinguishes the rubric's assessment classifications from proof of causal effects on actual consumer behavior.
